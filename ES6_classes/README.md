# ES6 Classes

## Learning Objectives

At the end of this project, you are expected to be able to explain to anyone, without the help of Google:

* How to define a Class
* How to add methods to a class
* Why and how to add a static method to a class
* How to extend a class from another
* Metaprogramming and symbols

## Requirements

* All files are interpreted/compiled on Ubuntu 20.04 LTS using `node 20.x.x` and `npm 9.x.x`
* Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
* All files end with a new line
* Code uses the `js` extension
* Code is tested using `Jest` and the command `npm run test`
* Code is verified against lint using ESLint
* Code needs to pass all the tests and lint, verified by running `npm run full-test`

## Setup

* Install NodeJS 20.x.x
* Install Jest, Babel, and ESLint as dev dependencies
* Run `npm install` from the project folder to install all necessary dependencies
