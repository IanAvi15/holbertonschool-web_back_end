# Python Variable Annotations

This project introduces type annotations in Python 3 and how they improve code clarity, correctness, and maintainability. You will learn how to annotate variables, functions, and classes, how Python uses duck typing, and how to validate your code using mypy. By the end of the project, you should be able to explain these concepts confidently without relying on external references.

# Learning Objectives

By completing this project, you will understand:

Type Annotations in Python 3
What type annotations are and why they matter

How Python uses them for static analysis rather than runtime enforcement

How to annotate variables, function parameters, return values, and class attributes

Function Signatures & Variable Types
How to write clear, explicit function signatures

How annotations help document expected input and output types

How to use typing tools such as List, Dict, Tuple, Union, Optional, and more

Duck Typing
The philosophy behind duck typing: “If it walks like a duck and quacks like a duck…”

How Python relies on behavior rather than strict type constraints

When duck typing is useful and when explicit type checking is safer

Validating Code with mypy
How to run mypy to perform static type checking

How to interpret mypy errors and warnings

How annotations help catch bugs before runtime

# Requirements

Environment
Ubuntu 20.04 LTS

Python 3.9

Allowed editors: vi, vim, emacs

Code Standards
All files must be executable

First line must be: #!/usr/bin/env python3

Code must follow pycodestyle 2.5

All modules, classes, and functions must include full documentation strings

Documentation must be meaningful, complete sentences

File lengths will be checked using wc

# Goal of the Project

The purpose of this project is to help you write clearer, safer Python code by using type annotations effectively. You will learn how to combine Python’s flexible dynamic typing with optional static analysis tools to produce code that is easier to understand, debug, and maintain.
