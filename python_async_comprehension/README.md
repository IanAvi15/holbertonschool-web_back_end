# Async Comprehension in Python

This project explores asynchronous generators, async comprehensions, and proper type‑annotation for asynchronous workflows. You will learn how Python’s asyncio framework enables efficient, non‑blocking iteration and how async comprehensions simplify consuming asynchronous data streams.

By the end of this project, you should be able to explain these concepts confidently without relying on external references.

# Learning Objectives

Asynchronous Generators
Understand how async def + yield create asynchronous generators

Learn how asynchronous iteration works using async for

Recognize when async generators are useful for streaming asynchronous data

Async Comprehensions
Use async comprehensions to collect values from asynchronous generators

Understand how async comprehensions improve readability and performance

Learn how they differ from regular list comprehensions

Type‑Annotating Generators
Properly annotate asynchronous generators using Python 3.8‑compatible types

Understand the structure of Generator[yield_type, send_type, return_type]

Apply type hints to async comprehensions and coroutine return values

# Goal of the Project

The purpose of this project is to help you understand how asynchronous iteration works in Python. You will learn how to build async generators, consume them efficiently using async comprehensions, and annotate them correctly for clarity and correctness.
